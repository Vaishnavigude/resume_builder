# Resume Builder – Flask Web App

A tool that lets users enter resume details via a form and generates a downloadable PDF.

## Features
- Web form input
- PDF generation
- Custom resume template

## Tech Stack
- Python
- Flask
- PDFKit / WeasyPrint

## How to Run
```bash
pip install flask pdfkit
python app.py
